# Endpoints

Client endpoint configuration guides for the homelab enterprise simulation.

## Contents

| Directory | Description |
|-----------|-------------|
| `windows10/` | Windows 10 client configuration and domain join |
| `windows11/` | Windows 11 client configuration and domain join |
| `linux/` | Linux client setup and domain integration |
| `joining/` | Step-by-step domain join procedure for all client types |
| `validation/` | Post-join testing and validation procedures |

## Usage
Complete the domain setup in `/ad/` before configuring endpoints.
Use `joining/` as the standard procedure, then validate with `validation/`.
