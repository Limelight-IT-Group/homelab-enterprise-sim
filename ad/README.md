# Active Directory

Configuration guides and documentation for the homelab Active Directory environment.

## Contents

| Directory | Description |
|-----------|-------------|
| `dns-dhcp/` | DNS and DHCP server configuration for the domain |
| `domain/` | Domain setup, forest configuration and initial provisioning |
| `gpo/` | Group Policy Object design, management and baseline policies |

## Usage
Follow the guides in order: domain setup first, then DNS/DHCP, then GPO management.
All configurations target a single-forest, single-domain lab environment running Windows Server 2022.
